# Sibani Pattanaik — Portfolio

Dark, animated Next.js portfolio for a frontend/full-stack developer.

## Run locally

```bash
npm install
npm run dev
```

## Before deploying

1. Replace `your-email@example.com` in `app/page.tsx`.
2. Add your real LinkedIn URL.
3. Put your final CV PDF at `public/Sibani-Pattanaik-CV.pdf`.
4. Update any project URLs that are not public.
5. Set the production domain in your deployment platform.
